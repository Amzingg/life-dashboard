# 🌿 Life Dashboard

A responsive personal productivity dashboard to track mood, habits, study hours, and expenses — all in one place.

---

## 📌 Overview

Life Dashboard is a web-based application designed to help users monitor their daily activities and visualize progress through analytics.  
The application focuses on clean UI, responsiveness, and structured data visualization using charts.

---

## ✨ Features

### 🏠 Dashboard
- Daily summary view
- Card-based layout
- Clean green-themed UI
- Fully responsive design

### 😊 Mood Tracker
- Log daily mood
- Mood trend visualization (Line Chart)

### ✅ Habit Tracker
- Add and track daily habits
- Habit completion analytics (Bar Chart)

### 📚 Study Tracker
- Log daily study hours
- Study time trend visualization

### 💸 Expense Tracker
- Add daily expenses
- View total spending
- Expense overview analytics

### 📊 Analytics
- Mood trend chart
- Habit completion chart
- Study time visualization
- Expense insights
- Monthly activity overview

### 🌙 Dark Mode
- Toggle between light and dark theme
- Optimized readability
- Consistent UI styling

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Chart.js
